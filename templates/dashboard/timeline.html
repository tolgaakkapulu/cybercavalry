{% load static %} {% comment %} Dashboard timelines — two Chart.js line charts side by side, half the screen each (Chart.js bundled locally at static/js/chart.umd.min.js for offline use): Blacklist Timeline — IP / Hash / URL blacklist ADDITIONS over the window. What the platform took in. Request Timeline — incoming API requests over the same kind of window, grouped into feed pulls / reports / rate-limited / other. What clients asked of the platform. Both open on "Last 24 hours · Hourly" (dashboard.views._TIMELINE_DEFAULT_*), and each card's range + granularity controls are independent so the two can be compared at different scales. The first paint uses the json_script payloads (timeline_init / request_timeline_init from dashboard.views.index) so there is no load-time flash; every later change fetches its own API endpoint. Both charts share one control implementation (makeTimeline below) — the only differences between them are the endpoint, the element ids and the series. The two cards are built to present an IDENTICAL frame regardless of what is in them, so the plot areas read as one row: a title row of its own, a fixed plot box, a fixed-height HTML legend (not Chart.js's in-canvas one) and a y-axis pinned to a constant width. See the style block for why each of those is needed. TO REMOVE THIS SECTION ENTIRELY: delete the single timeline include line (include "dashboard/timeline.html") in dashboard/index.html.
