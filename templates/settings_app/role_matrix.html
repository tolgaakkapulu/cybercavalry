API Authentication Model

API endpoints use a two-factor authentication model combining a per-user token with source IP allowlisting.

Token Auth

Each API User has their own token generated by an Admin.

Both Authorization: Token <token> and X-Username: <username> headers are required. The token must belong to the user in X-Username.

Source IP

All endpoints additionally require the caller's IP to be in the Allowed Source IP list.

Configure via Settings → Allowed Source IP. Requests from unlisted IPs are rejected with 403 regardless of token validity.

IP Blacklist Feed

GET /api/v1/blacklist/ uses source IP only — no token required.

Designed for firewalls and SIEM systems that pull the list automatically without managing user credentials.
