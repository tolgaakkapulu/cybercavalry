How a subscriber connects
Give it the discovery URL https://<your-host>/taxii/ and have it authenticate with HTTP Basic, where the username is an API User account and the password is that account's API token (mint one under Accounts → User Management). The subscriber then discovers the collections below and picks one.

The UUID is generated once and must stay stable — a subscriber stores it and re-polls that exact id. Pausing a collection keeps the UUID so it can resume without the subscriber re-discovering; deleting it does not.
